# Sohel Studio V3 — server-ready PWA

The page sends validated requests to `/.netlify/functions/generate`. The included Netlify Function validates input and deliberately remains in demo mode until an AI video provider is selected and configured.

**Deployment:** Netlify Functions require a Git-connected Netlify deploy or Netlify CLI. A static Netlify Drop upload may publish the page but does not deploy the function.

**AI model:** No provider, account, API key, or paid service is included yet. If an account or payment is needed, ask a parent or guardian to review and manage it. Never put API keys in browser code or share them in chat; credentials belong only in server-side environment variables.
